# Face Detection with OpenCV

Учебный проект по распознаванию лиц с помощью Python и OpenCV.

## Как работает
- Используется веб-камера
- Лица распознаются с помощью Haar Cascade
- Вокруг лица рисуется рамка
- По нажатию клавиши `s` лицо сохраняется в файл

## Файлы проекта
- `face_detection.py` — основной код программы
- `haarcascade_frontalface_default.xml` — обученная модель Haar Cascade

## Технологии
- Python
- OpenCV

## Примечание
В проекте используется готовая модель Haar Cascade.
